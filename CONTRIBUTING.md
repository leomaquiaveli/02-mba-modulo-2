# Guia de contribuição

Branches, padrão de commit, comandos e pull request estão no guia de Git do grupo: [`01_gerenciamento_de_tarefas/roteiro_execucao_pratica/03_GUIA_GIT.md`](./01_gerenciamento_de_tarefas/roteiro_execucao_pratica/03_GUIA_GIT.md).

Este arquivo guarda só o padrão das entregas analíticas.

## Padrão de análise

Toda entrega analítica deve declarar:

- pergunta de negócio;
- população e período;
- arquivos e colunas usados;
- tratamento de tempo, ausentes e categorias;
- método e baseline;
- métrica e incerteza;
- resultado;
- limitação;
- comando para reprodução.

## Checklist

- [ ] Links locais verificados.
- [ ] Nenhum dado bruto entrou no diff.
- [ ] Nenhum segredo entrou no diff ou no remote.
- [ ] Datas e população estão explícitas.
- [ ] Números têm fonte ou consulta.
- [ ] Código foi executado no ambiente documentado.
- [ ] Limitações foram registradas.
