# Redirecionamento do Data Room

O Data Room local canônico deste repositório é:

[`documentos/exhibits-m2/`](../exhibits-m2/README.md)

Não mantenha uma segunda cópia dos CSVs, do Parquet ou dos ZIPs nesta pasta. O script de auditoria, a documentação e as regras de proteção do Git usam `documentos/exhibits-m2/` como caminho padrão.

Este diretório permanece versionado apenas para impedir que instruções antigas criem dois Data Rooms concorrentes.
